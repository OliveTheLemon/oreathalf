## 🖥️ 주요 페이지

### 📍 Home

- 다이어트 마음 가짐을 담은 문구를 타이틀로 두었습니다.
- 하단에 다이어트 레시피에 자주 쓰이는 재료를 그리드로 보여줍니다.
- 재료 사진을 클릭하면 해당 재료 페이지로 이동합니다.

### 📍Ingredient

- 사이드 메뉴에서 해당 메뉴를 클릭하면 재료 목록 중 랜덤하게 이동합니다.
- [재료/요리/디자인] 세가지 카테고리의 사진이 있습니다.
- [요리] 사진 중 👆🏻로 커서가 바뀌는 것은 인스타그램 페이지로 이동합니다.
- 우측 하단 필터링 버튼으로 [전체 → 재료→ 요리 → 디자인] 카테고리 별로 사진을 모아 볼 수 있습니다.

### 📍 about

- o.eh!를 소개하는 페이지 입니다.

### 🧪 whatiatetoday

- 컨셉만 잡아둔 페이지 입니다.
- 식단을 기록할 수 있습니다.
- 데이터는 브라우저에 저장됩니다.
- 기록한 내용을 이미지로 저장할 수 있습니다.

### 🧪 random

- 컨셉만 잡아둔 페이지 입니다.
- 포스터를 만들기 위한 키워드를 생성할 수 있습니다.
- 4가지 카테고리의 랜덤 키워드를 얻을 수 있습니다.
- 카테고리 개별로 새로고침 가능합니다.
- 하단에서 제외할 키워드를 설정할 수 있습니다.
